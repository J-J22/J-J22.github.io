MISSION 02 · HEALTHTECH

SMRITI

An offline memory companion for elders in North-East India.

  • Cognitive games and memory help for elderly dementia patients, built for a Smart India Hackathon 2026 problem statement.
  • Two worlds: a calm patient side with no menus, timers or scores, and a normal caregiver dashboard.
  • Five adaptive activities, spoken reminders, and voice prompts with drop-in language packs.

MISSION 03 · DAILY DRIVER

REIATSUFLOW

My study planner for Linux. It turns my lists into a few tasks a day so I don't quit after 3 days.

  • I give it my lists (the AWS course, my syllabus, a DSA sheet) and it hands me a few tasks for the day.
  • Skip something and it just stays first in line tomorrow. Nothing turns red.
  • Do nothing for 3 days and it makes the next day lighter so I can get back into it.
  • Pomodoro built in, and it changes colours with my rice.
  • QML
  • Quickshell
  • Hyprland
